## Learned User Preferences

- UI copy is Spanish. Keep English loanwords with masculine articles: el frontier, el harness, este run.
- Avoid calques: página principal (not portada), harness (not andamio), run (not corrida), open weight (not peso abierto). Do not use codo or cuerda for the Pareto frontier.
- Prefer spoken, simple Spanish in methodology and UI copy; skip wording that sounds machine-translated.
